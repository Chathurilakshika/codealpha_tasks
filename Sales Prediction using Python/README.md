# Sales Prediction Using Python

This project analyzes advertising spend data to predict product sales using machine learning regression models. The dataset contains advertising budgets for TV, Radio, and Newspaper campaigns, along with the corresponding Sales values.

The main objective of this analysis is to understand how different advertising channels influence sales performance and to build a predictive model that can estimate future sales based on marketing spend.

## Project Workflow

The analysis includes the following steps:

- Loaded and inspected the advertising dataset
- Cleaned the data by removing unnecessary index columns
- Checked for missing values and duplicate records
- Performed exploratory data analysis using summary statistics and visualizations
- Studied relationships between advertising channels and sales using correlation analysis and scatter plots
- Selected TV, Radio, and Newspaper advertising spend as input features
- Trained regression models to predict Sales
- Evaluated model performance using R² Score, MAE, and RMSE
- Compared actual sales values with predicted sales values
- Analyzed the impact of advertising spend changes on sales outcomes
- Generated business insights for marketing strategy

## Key Insights

The analysis showed that TV advertising has the strongest relationship with sales, followed by Radio advertising. Newspaper advertising showed a comparatively weaker impact on sales. Based on the model results, businesses can improve marketing efficiency by prioritizing investment in TV and Radio campaigns while reviewing the effectiveness of Newspaper advertising.

## Conclusion

This project demonstrates how regression-based machine learning models can be used to predict future sales from advertising budgets. The results can help businesses make data-driven marketing decisions and optimize advertising spend across different channels.
